# Nova Studio Landing Page

This project is a modern landing page for a digital brand or creative studio. It is built using plain HTML and CSS and includes a polished hero section, navigation, feature highlights, pricing cards, and a call-to-action section.

The page is designed to showcase a business offering sleek visuals, bold typography, and a premium dark-theme aesthetic. It is responsive and works well across desktop and mobile screens.

## Features
- Modern dark gradient UI
- Sticky top navigation
- Hero section with CTA buttons
- Feature cards for services
- Pricing section
- Responsive layout for mobile devices

## Files
- `index.html` — main page structure and styling
- `nova head.png` — branding asset used in the logo area
